## Reproduce the local review

Precondition: locked Python dependencies installed as documented in prototype/README.md, plus `npm ci` in prototype/web. From `prototype/web`:

```sh
npm run review:receipts
```

It exports actual `ROOM_LLM=stub` receipts and starts Vite. Override `GOLDEN_PYTHON` for an interpreter outside `prototype/.venv`; validation used the existing locked T-015 venv, not a new dependency resolution. The reviewer’s server runs at `http://127.0.0.1:5199/` with `--host 127.0.0.1 --port 5199`.

Independent export, from prototype:

```sh
ROOM_LLM=stub PYTHONPATH=server:.. python -m golden export web/public/review/golden-receipts.json
```

With the gallery running, from prototype/web:

```sh
node review/check.mjs
```

The data is a development example, clearly synthetic. It is not a production student preview and must not be used with real student records. Teacher question text is not exposed through a pretend preview workflow.
