## Proposed decisions (the checker takes these to the founder; nothing here is decided)
The full text of each is in RESULT.md, "Proposed design changes".
- **PD-S1-1: node set.** Add `heading` (levels 1–3), `bullet_list`, `ordered_list`, `list_item`, `blockquote`, `hard_break`, plus the formatting marks `em` and `strong` (italic titles in references). No tables, images, code, links or footnotes in v1. Decide before golden logs exist (D33).
- **PD-S1-2: typed text never carries a claim mark**, even inside a `by: student` link. A claim comes only from an explicit link action. Recommended: keep as built.
- **PD-S1-3: event-log.md §5.** The step log holds only the primitive step types both replays know. The editor flattens `markSet`, and replay rejects any other type.
- **PD-S1-4: event-log.md §5.** `doc_hash = sha256(canonical_json(doc.toJSON()))`, using the chain's canonical JSON.
- **PD-S1-5: pin the editor and replay libraries as a pair** (@tiptap/pm 3.32.0 → prosemirror-transform 1.12.x; prosemirror-py 0.6.1). Upgrading either requires the S1 parity fixtures and the Chromium pass to pass again. Record the pair in the engine stamp.
- **PD-S1-6: event-log.md §4 `input_kind`.** Dictation cannot be told apart in browsers, and extension edits that bypass `beforeinput` count as `keyboard`. The replacement count is therefore a lower bound; the receipt wording should say "reported by the browser".
- **PD-S1-7:** add Playwright and a pinned Chromium to CI at M3, so the Chromium fixture is regenerated and checked on every editor change.
