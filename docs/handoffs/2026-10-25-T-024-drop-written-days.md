## What changed

- `prototype/server/engine/receipt/summary.py`
  - Removed the `editor.batch` scan and the distinct-day count. The summary no longer reads batch timestamps or any edit timing.
  - The first sentence is now always the existing zero-day branch: `"Written " + SUMMARY_SOURCES[n]`, e.g. "Written with 2 sources." No other clause changed.
  - Removed `editor.batch` sequence IDs from `summary.event_ids`; they were cited only as evidence for the day count. The remaining IDs are the seal, `source.add`, paste, declared-help and Coach events.
- `prototype/server/engine/receipt/copy.py`
  - Removed `SUMMARY_DAYS`; `SUMMARY_SOURCES` and every other string are unchanged.
- `prototype/server/tests/test_receipt_compile.py`
  - Replaced the old "summary cites the batches behind the days" test with `test_summary_does_not_use_edit_batches_or_count_days`: batches exist, none appear in `summary.event_ids`, and the text has no "Written on" and no day/session/duration/time-unit word.
- `prototype/server/tests/test_golden_sessions.py`
  - Added `test_summary_has_no_day_session_or_duration_count`, parametrized over all twelve golden sessions: no "Written on", no day/session/duration/time-unit word, and no batch event ID in the summary.
