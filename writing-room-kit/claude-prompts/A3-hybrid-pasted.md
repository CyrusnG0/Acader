# A3 — Hybrid, pasted (evidence INSIDE, writing OUTSIDE)
1. Work like A1 for evidence: ask 8–12 questions via the librarian in your own words.
2. Then run `python3 scripts/outside.py write work/A3-<N>.draft.json work/A3-<N>.txt`. That pastes your retrieved passages into an outside AI, gets an essay back, and clicks citations in. Do not edit the essay.
3. Notes: one line or empty. Finalise with `--struct pasted --writer deepseek-chat`.
