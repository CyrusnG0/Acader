Before you start

This is a practice session and is not graded. Your code is sent to an AI provider (Anthropic) to write questions about it. We store your code and answers for 30 days, then delete them. You can export or delete them yourself at any time. Your instructor sees summary signals (how many questions you answered, answer length, time). They see your full answers only if you tick the second box. If you would rather not, close this page and use your instructor's normal route.
